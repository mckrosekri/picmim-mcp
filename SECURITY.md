# Security Policy

Report security vulnerabilities privately to **info@picmim.com**. Include enough detail to reproduce the issue, but do not send access tokens, refresh tokens, OAuth client secrets, passwords, customer data, or production signing keys by email or in a public GitHub issue.

For ordinary setup and product questions, use the same support address or Picmim's in-product support channel.

Public GitHub issues are appropriate only for non-sensitive documentation problems in this repository.
